Identity / state / spending

Anonymous access, bounded processing

Resident sign-in is not required. Workload identities and application controls still constrain every service hop.

Workload identity

Web/API managed identities; not BC Services Card or a government-record connection.

Page-scoped state

Drafts and displayed answers stay in tab memory. Reload or Start over clears the local conversation.

Sharing starts off

Version-5 personal context is opt-in and minimized. It never becomes a Search query or embedding.

Atomic controls

Shared ownership, leases, cancellation, daily allowance and conservative failure accounting.

Telemetry boundary

Operation metadata, not automatic prompt logging. Provider/platform retention is a separate boundary.

No residency shortcut

Canada Central hosting does not prove Global Standard inference stays in Canada.

Estimated application budgets are not a hard Azure invoice cap. Cancellation does not erase potentially billable work.
